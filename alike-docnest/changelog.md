# Changelog — aLike DocNest

## 0.1.0 — first release (closed testing)

The first closed-testing release. Highlights:

- **Family members** — add profiles (name, relationship, blood group, photo, emergency contact); your
  own "Self" profile is protected.
- **Documents** — scan with the camera (on-device), import files, automatic on-device text recognition
  (OCR) to pre-fill details, organize by category and member.
- **Find & remind** — search across documents; renewal reminders for expiring documents.
- **Privacy & security** — works offline, no account; data encrypted at rest; optional PIN/biometric
  app lock.
- **Backup** — optional encrypted backup/restore to your own Google Drive.
- **Onboarding** — multi-language first-run (English, हिन्दी, मराठी, தமிழ், తెలుగు, ಕನ್ನಡ).
